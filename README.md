# شاملتي — الموقع والإصدارات

هذا مستودعُ **النشر** لبرنامج «شاملتي — المنصة البحثية الشاملة» (مشروع الكُتُبي):
صفحةُ التعريف، وصفحةُ طريقة الاستخدام، والملفُّ التنفيذيّ في الإصدارات.

- **[⬇ حمِّل البرنامج](https://github.com/aburaji/shamelaty-app/releases/latest/download/Shamelaty.exe)**
- [طريقة الاستخدام](https://aburaji.github.io/shamelaty-app/how.html)
- [تليغرام](https://t.me/DRRESNiChannel)

## ما هو

برنامجٌ يبحث في مكتبتك من **المكتبة الشاملة ٤** على جهازك: بحثٌ لفظيٌّ دقيق،
وقراءةٌ للصفحة كاملةً، ومصادرُ منضبطة. ملفٌّ واحد يُنقر مرّتين — بلا تثبيت،
وبلا إنترنت.

**ويُقرأ مجلَّد الشاملة ولا يُكتب فيه حرف.**

## ما في هذا المستودع

الصفحتان وأصولُهما فقط. أمّا شيفرةُ البرنامج فليست هنا.

> الصفحاتُ مولَّدةٌ من مشروع «شاملتي» بـ`npm run site:sync` — فلا تُحرَّر هنا،
> إذ يُعاد توليدُها فتُمحى.
